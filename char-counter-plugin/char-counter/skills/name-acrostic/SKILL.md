# Name acrostic

Given a name:

1. Take its letters in order; ignore spaces. One line per letter.
2. Each line starts with that letter, capitalized and visually set off
   (e.g. `**A** — ...`).
3. The lines should join into one small coherent portrait or scene — not a list
   of unrelated words.
4. Keep every line under ~8 words.

Output only the acrostic. If no name is given, ask for one first.
