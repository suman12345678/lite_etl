# Security classification

- **Overall dataset classification:**  public | internal | confidential | restricted
- **Contains:**                        PII? PCI? PHI? export-controlled?
- **Field-level tags:**                see field-mapping.csv `pii_class` column
- **Masking policy:**                  which `config/masking/policies.yaml` policy applies
- **Access:**                          who may read the landed data
- **Residency / region:**              where data may be processed / stored
- **Retention:**                       how long landed partitions are kept
- **Secret storage:**                  vault path / secret-manager key for credentials
